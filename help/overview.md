# Google Calendar

This extension renders a public Google Calendar ICS feed as Cannon frontend pages.

Configure the calendar title, public ICS URL, refresh interval, description summary length, and whether online meeting details require a signed-in user.

Routes can choose a default calendar view when assigned in Cannon. Visitors can switch between calendar grid, month list, year list, and day views.

The page template is embedded as `calendar/page.html` and can be overridden from Cannon's template override tools.
